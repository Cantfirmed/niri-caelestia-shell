# Design: Biri Shaders Live Uniform Studio & M3 Palette Binding

## Overview
Niri allows running custom GLSL shaders for window open/close animations, active borders/focus rings, and full-screen color filters.
Currently, `services/BiriShaders.qml` toggles static shader presets by updating `niri/shaders.kdl`. Tweaking shader parameters requires manually editing GLSL files, and shader colors do not dynamically follow Material 3 wallpaper/theme accent color shifts.

## Architecture & Implementation

### 1. Dynamic GLSL Template Engine
- In `services/BiriShaders.qml`:
  - When the user changes wallpaper or switches color schemes (`Colours.palette`), regenerate active shader GLSL files from templates in `niri/shaders/templates/`.
  - Inject current RGB/RGBA values into uniform constants:
    ```glsl
    // Auto-generated by Caelestia BiriShaders
    const vec3 THEME_PRIMARY = vec3(0.35, 0.65, 0.95);
    const vec3 THEME_SECONDARY = vec3(0.85, 0.45, 0.75);
    ```

### 2. Live Uniform Sliders in Nexus
In `modules/nexus/pages/ShadersPage.qml`:
- Expose sliders with real-time preview:
  - **Focus Ring**: Width, spread, pulse speed, light spill intensity.
  - **Window Animation**: Duration, whirlpool twist angle, scale damping.
  - **Screen FX**: Vignette strength, chromatic aberration offset, scanline darkness.

### 3. Presets & Hot-Reload
- Preset switcher in the Mod+B quick shader menu.
- Safe reload trigger: write changes and signal Niri via IPC reload without stuttering ongoing window animations.
