# Background & Wallpaper Transition Subsystem — Developer & Agent Guide

The **Background Subsystem** (`modules/background/`) manages desktop wallpaper rendering, clock overlays, audio visualizers, and animated transitions across all connected outputs on Wayland/Niri.

Transitions use the **pocket-dots** shader architecture, executing procedural Dijkstra wave-front contagion (`contagio`) and character silhouette cutout (`perfil`) transitions directly in the Quickshell scene graph.

---

## 1. Directory Structure

| File / Path | Purpose |
|-------------|---------|
| `modules/background/Background.qml` | Root layer-shell background window (`WlrLayer.Background`) mapped over `Screens.screens`. Houses `Wallpaper`, `Visualiser`, and `DesktopClock`. |
| `modules/background/Wallpaper.qml` | Wallpaper presentation layer. Manages static `CachingImage` displays, file missing fallbacks, preview bypass, and transition lifecycle handover. |
| `modules/background/WallpaperTransition.qml` | Hardware-accelerated `ShaderEffect` viewport rendering the active transition shader with dynamic aspect ratio cover calculation. |
| `modules/background/shaders/wallfx.frag` | GLSL fragment shader implementing `contagio` (procedural burning ember cells, sparks, front glow, camera settle) and `perfil` (BiRefNet outline silhouette, pen contour stroke, world expansion). |
| `modules/background/shaders/wallfx.frag.qsb` | Multi-target compiled shader binary (SPIR-V, GLSL 100es/120/150/300es, HLSL, MSL) generated by Qt Shader Baker (`qsb`). |
| `services/WallFx.qml` | Singleton service coordinating transition triggers, palette color extraction, python map generation, and frame rate benchmarking. |
| `services/Wallpapers.qml` | Singleton service managing current wallpaper path, matugen color generation, filesystem scanning, and IPC hooks. |
| `scripts/wallfx.py` | Python map generator utilizing numpy and PIL to generate 16-bit packed PNG fields and precompute the 12-slot contagion cache pool. |

## 2. Architecture & Pipeline

Unlike compositors using external daemons (`swww`, `mpvpaper`, `awww`), Caelestia renders wallpaper directly in Quickshell on `WlrLayer.Background`.

```
                    ┌────────────────────────────┐
                    │ Wallpapers.setWallpaper()  │
                    │   or IPC: wallfx trigger   │
                    └─────────────┬──────────────┘
                                  │
                                  ▼
                    ┌────────────────────────────┐
                    │    services/WallFx.qml     │
                    │   (Coordinates lifecycle)  │
                    └─────────────┬──────────────┘
                                  │
          ┌───────────────────────┴───────────────────────┐
          │ (Async Process)                               │ (Sync State)
          ▼                                               ▼
┌──────────────────┐                            ┌──────────────────┐
│ scripts/wallfx.py│                            │ Derive Palette   │
│ elige <new_path> │                            │ Colors (M3)      │
└─────────┬────────┘                            └─────────┬────────┘
          │ (map / line paths)                            │ (ember, ink)
          └───────────────────────┬───────────────────────┘
                                  │
                                  ▼
                    ┌────────────────────────────┐
                    │  WallpaperTransition.qml   │
                    │  ShaderEffect (wallfx.qsb) │
                    │       t: 0.0 ──► 1.0       │
                    └─────────────┬──────────────┘
                                  │
                                  ▼ (t = 1.0 finished)
                    ┌────────────────────────────┐
                    │   modules/Wallpaper.qml    │
                    │ CachingImage (opacity: 1)  │
                    │   Seamless Handover Done   │
                    └────────────────────────────┘
```

## 3. Shader Pipeline (`wallfx.frag`)

The fragment shader reads two wallpaper textures (`oldTex`, `newTex`) and two 16-bit packed control maps (`fieldTex`, `lineTex`):

- **Contagion (`contagio`)**:
  - `fieldTex`: R (high byte), G (low byte) encode arrival time ranked by area (0..65535).
  - `lineTex`: G (high byte), B (low byte) encode a smooth Gaussian-blurred arrival surface for edge glow.
  - 4px pixel-art cells eat through the old wallpaper along procedural Perlin noise fronts.
  - Flipped cells burn in the `ember` color (derived from palette), sparks leap ahead of the front, and the camera subtly zooms and settles.
- **Outline (`perfil`)**:
  - `fieldTex`: G encodes depth inside character; B encodes signed distance to silhouette.
  - `lineTex`: R encodes pen stroke drawing parameter; G/B encode outside arrival surface.
  - Draws a thin `ink` contour line, fills inward, and spreads outward in 4px cells.

### Aspect Ratio Cover Calculation
Because wallpapers have arbitrary dimensions and aspect ratios, `WallpaperTransition.qml` computes UV transform vectors:
```javascript
function crop(img) {
    const iw = Math.max(img.implicitWidth, 1);
    const ih = Math.max(img.implicitHeight, 1);
    const s = Math.max(root.width / iw, root.height / ih);
    const w = root.width / (iw * s);
    const h = root.height / (ih * s);
    return Qt.vector4d((1 - w) / 2, (1 - h) / 2, w, h);
}
```
In the shader, image sampling maps normalized screen coordinates:
```glsl
vec3 oldAt(vec2 uv) { return texture(oldTex, cropOld.xy + uv * cropOld.zw).rgb; }
vec2 newUv(vec2 uv, float z) { return cropNew.xy + cam(uv, z) * cropNew.zw; }
```
This guarantees zero image stretching, automatic centered cropping, and dynamic resizing across resolution or orientation changes.

### Compiling Shaders
If `wallfx.frag` is modified, recompile the `.qsb` binary with:
```bash
/usr/lib/qt6/bin/qsb --qt6 --glsl "100 es,120,150,300 es" -o modules/background/shaders/wallfx.frag.qsb modules/background/shaders/wallfx.frag
```

## 4. Map Generator (`scripts/wallfx.py`)

`scripts/wallfx.py` produces the 16-bit packed control maps:

- **Contagion Pool**: Precomputes 12 pairs of `spread-k.png` and `spread-k-liso.png` in `~/.cache/caelestia/wallfx/spread/`. When a map is used, `wallfx.py` returns immediately and forks a background process to renew the slot.
- **Outline Extraction**: If `rembg` (BiRefNet) and OpenCV are installed, extracts the character mask and caches results in `~/.cache/caelestia/wallfx/perfil/`. If rembg is not installed, it falls back cleanly to `contagio` with zero errors.

### CLI Usage:
```bash
# Pre-warm the 12-slot contagion pool
./scripts/wallfx.py warm

# Query maps for a wallpaper transition
./scripts/wallfx.py elige ~/Pictures/wallpapers/anime.png
# Outputs: contagio /path/to/spread-0.png /path/to/spread-0-liso.png
```

## 5. Configuration (`shell.json`)

Configure transition behavior in `shell.json` under `"background"`:

```json
{
  "background": {
    "enabled": true,
    "wallpaperEnabled": true,
    "transition": {
      "enabled": true,
      "type": "contagio",
      "duration": 1800,
      "glow": 0.9
    }
  }
}
```

C++ reflection is backed by `BackgroundTransition` in `plugin/src/Caelestia/Config/backgroundconfig.hpp`.

## 6. IPC Interface

Interact with the transition subsystem via Quickshell IPC:

```bash
# Trigger an automatic transition between two wallpapers
qs -c niri-caelestia-shell ipc call wallfx trigger "/path/to/old.png" "/path/to/new.png"

# Play with explicit maps
qs -c niri-caelestia-shell ipc call wallfx play "/path/to/old.png" "/path/to/new.png" "contagio" "/path/to/map.png" "/path/to/line.png"

# Check transition framerate statistics
qs -c niri-caelestia-shell ipc call wallfx stats
# e.g.: contagio: 216 frames in 1800 ms (120 fps), worst 25 ms

# Cancel any active transition
qs -c niri-caelestia-shell ipc call wallfx stop
```

## 7. Critical Invariants & Gotchas

1. **Desktop Decoupling & Preview Bypass Invariant**:
   - `modules/background/Wallpaper.qml` binds to `Wallpapers.actualCurrent`, while `Wallpapers.preview(path)` drives `Wallpapers.current` (used for launcher card previews and dynamic M3 palette preview).
   - While the user scrubs or browses wallpapers in the launcher carousel (`Super+W`), the desktop background remains stable on `actualCurrent`.
   - When a wallpaper is selected with Enter or click, `Wallpapers.setWallpaper(selectedPath)` updates `actualCurrent` and fires `WallFx.trigger(oldWall, selectedPath)`. The launcher closes, and the desktop performs the full pocket-dots transition from the previous wallpaper to the chosen wallpaper. Heavy shader transitions are never thrashing during hover scrubbing.
2. **Seamless Handover Invariant**:
   - At `t = 1.0`, the shader output is pixel-identical to `newTex`.
   - In `Wallpaper.qml`, `onSourceChanged` instantiates the new `CachingImage` with `opacity: 1` immediately at the start of the transition.
   - The new image decodes asynchronously behind the opaque running `ShaderEffect` viewport (`z: 1`) during the 1.8s–2.0s transition.
   - The old image is destroyed safely behind the running shader once the new image reports `status === Image.Ready`.
   - When the transition finishes at `t = 1.0` and `WallpaperTransition` hides, the new image is already decoded and rendered at `opacity: 1`, ensuring zero flash of the old wallpaper.
3. **Threaded Render Loop Compatibility**:
   - `QSG_RENDER_LOOP=threaded` must be preserved.
   - Control textures (`oldImg`, `newImg`, `fieldImg`, `lineImg`) use `asynchronous: true` to ensure image decoding happens off the Qt Quick GUI thread.
   - `scripts/wallfx.py` executes in an asynchronous `Process` child process.
4. **Dynamic Watchdog & Un-cached Safeguards**:
   - `services/WallFx.qml` maintains a dynamic watchdog timer (20s during preparation to give BiRefNet AI outline extraction sufficient time for brand-new or high-resolution wallpapers, 8s during texture load, and animation duration + 1000ms during run). If any phase stalls, it auto-finishes cleanly to static display to guarantee the desktop never hangs.

## 8. Nexus Wallpaper Download Integration

When downloading wallpapers online via Nexus (`modules/nexus/pages/wallandstyle/WallpaperOnline.qml`):
- Upon download completion from Wallhaven, `WallpaperOnline.qml` executes `prepareProcess` (`scripts/wallfx.py perfil <path>`) asynchronously while displaying `"Preparing wallpaper transition..."`.
- The BiRefNet character outline maps are pre-computed in `~/.cache/caelestia/wallfx/perfil/` before closing Nexus.
- `Wallpapers.setWallpaper(path)` is then invoked, triggering an instantaneous pocket-dots `perfil` transition on the desktop at 120 FPS.
